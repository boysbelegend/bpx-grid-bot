# 📋 시나리오 템플릿 가이드

BPX Grid Bot의 시나리오 템플릿 시스템을 사용하면 복잡한 설정 없이 즉시 트레이딩을 시작할 수 있습니다.

---

## 🎯 시나리오 시스템 개요

### 무엇인가요?

시나리오 템플릿은 **사전 정의된 트레이딩 전략 설정**으로, 경험 수준과 리스크 성향에 맞게 최적화되어 있습니다.

### 왜 사용하나요?

- ✅ **빠른 시작**: JSON 파일 편집 불필요
- ✅ **검증된 설정**: 백테스팅으로 검증된 파라미터
- ✅ **리스크 관리**: 경험 수준에 맞는 안전한 설정
- ✅ **커스터마이징**: 필요시 자유롭게 수정 가능
- ✅ **스마트 추천**: AI 기반 맞춤 추천

## 📊 사전 정의된 시나리오

### 현물 거래 시나리오 (3개)

#### 1. 보수적 현물 (Conservative Spot)
```
리스크: ⭐ (낮음)
권장: 초보자, 변동성 낮은 시장
```

**설정:**
- 그리드 레벨: 20개
- 간격: 2.0%
- 레벨당 수량: 0.03
- 최대 포지션: 10.0
- 일일 손실 한도: $100
- 긴급 손절: 20%

**장점:**
- 낮은 리스크
- 안정적인 수익
- 큰 자본으로 운영 가능
- 장기 운영에 적합

**단점:**
- 낮은 수익률
- 큰 초기 자본 필요
- 수익 실현이 느림

**필요 자금 (SOL @ $200):**
- Base: 20 × 0.03 = 0.6 SOL (~$120)
- Quote: 20 × 0.03 × 200 = $120
- **총: ~$240** (권장: $500+)

---

```
리스크: ⭐⭐ (중간)
권장: 중급자, 일반적인 시장 조건
```

**설정:**

- 간격: 1.0%
- 레벨당 수량: 0.05
- 최대 포지션: 10.0

- 다양한 시장 조건에 적응
- 적절한 자본으로 시작 가능

**단점:**
- 변동성 높을 때 주의 필요
- 중간 정도의 모니터링 필요

**필요 자금 (SOL @ $200):**
- Base: 20 × 0.05 = 1.0 SOL (~$200)
- Quote: 20 × 0.05 × 200 = $200

## 🚀 사용 방법

### 1. API로 시나리오 조회

```bash
# 모든 시나리오 조회
curl http://localhost:3001/api/scenarios

# 현물만 조회
curl http://localhost:3001/api/scenarios?marketType=spot

# 선물만 조회
curl http://localhost:3001/api/scenarios?marketType=futures

# 특정 시나리오 상세 조회
curl http://localhost:3001/api/scenarios/futures-moderate
```

### 2. 맞춤 추천 받기

```bash
curl -X POST http://localhost:3001/api/scenarios/recommendations \
  -H "Content-Type: application/json" \
  -d '{
    "experience": "beginner",
    "riskTolerance": "low",
    "marketType": "spot"
  }'
```

**프로필 옵션:**
- `experience`: `beginner`, `intermediate`, `expert`
- `riskTolerance`: `low`, `medium`, `high`
- `marketType`: `spot`, `futures`

### 3. 시나리오 내보내기

```bash
curl -X POST http://localhost:3001/api/scenarios/export \
  -H "Content-Type: application/json" \
  -d '{
    "scenarioId": "futures-moderate",
    "symbol": "SOL-PERP",
    "baseAsset": "SOL",
    "quoteAsset": "USDC",
    "dryRun": true
  }'
```

응답받은 JSON을 `config/strategies/` 폴더에 저장하고 사용하세요.

### 4. 대시보드에서 사용 (권장)

프론트엔드 대시보드를 사용하면 클릭 몇 번으로 시나리오를 선택하고 시작할 수 있습니다:

```bash
# 대시보드 시작
cd dashboard/frontend
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 후:
1. "시나리오 선택" 탭 클릭
2. 원하는 시나리오 선택 또는 추천 받기
3. 심볼과 자산 입력
4. "전략 설정 생성" 클릭
5. "이 설정으로 시작" 클릭

## 🎨 커스터마이징

### 기본 시나리오를 수정하려면

1. **대시보드 사용 (가장 쉬움):**
   - 시나리오 선택
   - "커스터마이즈" 버튼 클릭
   - 원하는 값 수정
   - "저장하기" 클릭

2. **API 사용:**

```bash
# 커스텀 시나리오 생성
curl -X POST http://localhost:3001/api/scenarios/custom \
  -H "Content-Type: application/json" \
  -d '{
    "name": "내 SOL 전략",
    "description": "SOL 전용 커스텀 설정",
    "baseScenarioId": "futures-moderate",
    "customizations": {
      "grid": {
        "levels": 20,
        "spacing": { "type": "percentage", "value": 1.2 }
      },
      "risk": {
        "maxPositionSize": 3.0,
        "maxDailyLoss": 75
      }
    }
  }'
```

### 커스터마이징 가능한 항목

**그리드 설정:**
- `levels`: 그리드 레벨 수 (5-50)
- `spacing.value`: 레벨 간 간격 (0.1-10%)

**주문 설정:**
- `quantityPerLevel`: 레벨당 주문 수량

**리스크 설정:**
- `maxPositionSize`: 최대 포지션 크기
- `maxPositionValue`: 최대 포지션 가치 (USD)
- `maxDailyLoss`: 일일 손실 한도 (USD)
- `emergencyStopLoss`: 긴급 손절 (%)

**선물 설정 (선물만):**
- `leverage`: 레버리지 (1-20x)
- `marginMode`: 마진 모드 (`cross`, `isolated`)
- `liquidationBuffer`: 청산 버퍼 (%)

## 📈 시나리오 선택 가이드

### 초보자라면

**현물:**
1. "보수적 현물" 시작
2. 1-2주 운영 후 "균형 현물"로 업그레이드
3. 충분한 경험 후 "공격적 현물" 고려

**선물:**
1. "초보수적 선물" (1x)로 시작 **필수**
2. 2-4주 운영 후 "보수적 선물" (2x)
3. 충분한 경험과 이해 후에만 더 높은 레버리지

### 중급자라면

**현물:**
- "균형 현물" 추천
- 변동성 낮은 시장: "보수적 현물"
- 변동성 높은 시장: "공격적 현물"

**선물:**
- "균형 선물" (3x) 추천 ⭐
- 안전 우선: "보수적 선물" (2x)
- 공격적 트레이딩: "공격적 선물" (5x)

### 전문가라면

**현물:**
- 모든 시나리오 사용 가능
- 시장 조건에 따라 선택
- 커스터마이징 적극 활용

**선물:**
- "공격적 선물" (5x) 또는 "극공격적 선물" (10x)
- 실시간 모니터링 체계 필수
- 청산 리스크 완전 이해 필수

## ⚠️ 중요 주의사항

### 시나리오 사용 전

1. ✅ **백테스팅 필수**: 선택한 시나리오를 최소 7일 백테스트
2. ✅ **Dry Run 테스트**: 최소 24시간 시뮬레이션 모드 운영
3. ✅ **충분한 자금**: 필요 자금의 2-3배 준비
4. ✅ **소액 시작**: 처음엔 최소 수량으로 시작
5. ✅ **모니터링**: 첫 일주일은 매일 확인

### 선물 거래 특별 주의

**레버리지별 모니터링:**
- 1-2x: 주 1-2회 확인
- 3-5x: 일 1-2회 확인
- 5x 이상: **실시간 모니터링 필수**

**청산 방지 체크리스트:**
- [ ] 청산 버퍼 경고 없는지 확인
- [ ] 마진 비율 60% 미만 유지
- [ ] 펀딩 레이트 0.1% 미만 확인
- [ ] 충분한 여유 담보 보유

### 리스크 관리

**절대 규칙:**
- 전체 자산의 10-20%만 한 봇에 투입
- 일일 손실 한도를 자산의 1-3%로 설정
- 이해하지 못하는 설정은 사용 금지
- 손실 허용 범위 초과시 즉시 중단

## 💡 팁과 트릭

### 성공적인 운영을 위한 팁

1. **시장 분석**:
   - 레인징 시장: 좁은 간격, 많은 레벨
   - 트렌딩 시장: 넓은 간격, 적은 레벨

2. **자금 관리**:
   - 항상 필요 자금의 2-3배 보유
   - 재조정 대비 여유 자금 확보
   - 인벤토리 스큐 0에 가깝게 유지

3. **수익 극대화**:
   - 변동성 높은 시간대 활용
   - 펀딩 레이트 유리한 방향 포지션
   - 정기적인 수익 실현

4. **손실 최소화**:
   - 일일 손실 한도 보수적 설정
   - 긴급 손절 항상 활성화
   - 강한 트렌드 시 일시 중단
